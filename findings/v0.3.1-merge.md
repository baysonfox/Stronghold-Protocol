# 升级合并记录：v0.3.0 → v0.3.1（官方皮肤上游化与双上游演进）

## 1. 背景与目标

本分支在 `upstream` (`sganggs/Stronghold-Protocol`) 基础上维护了三项核心特性：
- **干员皮肤系统（Fusion Skins）**：内置 271 款干员时装资产（Spine 骨骼与高清头像）、客户端选皮与服务端实时广播同步。
- **维护通知与禁开局倒计时**：顶部黄色跑马灯通知横幅、15 分钟维护倒计时及 `/admin/maintenance` 接口。
- **蓝绿零停机部署**：双实例共享目录、活跃对局排空检查及 `/admin/matches`、`/admin/rooms` 接口。

本次升级对齐了官方上游的最新发布 `v0.3.1`（及后续 0.3.2 补丁 `c9d804f4`），并全面核查采纳了 `paper` (`Paper-Yuan/Stronghold-Protocol`) 在 `v0.3.1.1` (`paper/align/0.3.0`) 中的优质修复。

## 2. 上游核心更新与演进

### 2.1 `upstream/master` (`v0.3.1` + `0.3.2` 补丁)
- **干员皮肤系统官方原生实装（PR #685 / #686 by @Flotiarenor）**：
  - 确立了官方契约：按玩家座位选择皮肤、按单位所有者（owner）渲染。
  - 新增设置项「显示其他玩家的皮肤」（默认开启，可关闭以仅展示默认骨骼）。
  - 支持整备期与战斗中换皮实时刷新 owner 视角、侦察视角与同盟队友，替身（stand-in）按本体干员解析皮肤，支持 Forge 模组服装联动。
  - Display-only 规范：仿真器内仅传递纯展示数据，完全不影响战斗逻辑与 288 个黄金场景确定性。
- **战斗引擎与视觉特效重大修复**：
  - 余 S3「烈火燎原」火墙官方组件渲染（YuWall，多段式火焰帷幕贯穿棋盘）。
  - 瑕光 S2 动作切片修复，野鬃 S2 起手特效、缪尔赛思 S3 流形形态保持、魔王 S2 循环特效补完。
  - 琳琅诗怀雅 S3 机制对齐官方卫戍协议（技能不自动关闭、保留金币且不发射爆弹）。
- **工具链与系统优化**：
  - 设置面板新增「清理旧版本素材」功能（安全清理本地无用的导入缓存）。
  - 支持按需下载非干员池干员的官方数据表（On-demand official tables）。
  - Windows 环境路径分隔符与导出夹具修复，兼容 Python 3.8–3.11。

### 2.2 `paper` (`v0.3.1.1`) 关键体验修复采纳
- **调配面板换皮立绘立即刷新（`c3a9994c`）**：
  - 原 LoadoutScreen 仅订阅 `loadoutStore`，换皮后虽然底层数据变更，但组件未重渲染，卡片与详情页仍显示旧立绘。
  - 本次合入对 `skinsStore` 的状态监听，换皮瞬间立即重绘立绘与头像。
- **皮肤语音 `#` 字符 URL 编码转义（`3ffee615`）**：
  - 皮肤语音目录带 `#`（例如 `char_472_pasngr_epoque#17`），而在标准 URL 解析中 `#` 会被视作片段标识符导致路径截断报 404。
  - 在 `public/js/media.js` 中将路径内的 `#` 转义为 `%23`，彻底修复皮肤语音试听 404 问题。
